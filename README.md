# 📚 Sobre o Projeto

O **PROJETO_ADS_2026_1_SEMESTRE** é uma aplicação web desenvolvida com foco acadêmico e prático, buscando aplicar conceitos de:

- Desenvolvimento Web com Flask
- Estruturação de aplicações Python
- Banco de dados SQLite
- Templates HTML
- Organização de arquivos estáticos
- CRUD de dados
- Integração entre backend e frontend

O sistema foi construído para consolidar conhecimentos adquiridos durante o semestre e demonstrar habilidades práticas em desenvolvimento full stack básico.
